Reproducibility
===============

Code for reproducing the figures in our manuscript is available at
`aster-ww/SVC-reproducibility <https://github.com/aster-ww/SVC-reproducibility>`_,
where each figure has a notebook together with the precomputed files it reads.

The processed data and the trained model checkpoints are deposited on Zenodo:
`10.5281/zenodo.22693727 <https://doi.org/10.5281/zenodo.22693727>`_.
