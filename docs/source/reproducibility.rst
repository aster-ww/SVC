Reproducibility
===============

Code for reproducing the analyses and main figures of the manuscript is available in the
`SVC-reproducibility <https://github.com/aster-ww/SVC-reproducibility>`_ repository.

Processed data and model checkpoints are available on Zenodo:
`10.5281/zenodo.22693727 <https://doi.org/10.5281/zenodo.22693727>`_.
